# Autistic Premades

Foundry VTT module. Install from **Setup → Add-on Modules → Install Module** using this Manifest URL:

```
https://github.com/Shizorium/Autistic_Premades/releases/latest/download/module.json
```

## Releases

1. Push changes to `main`.
2. On GitHub: **Releases → Draft a new release**.
3. Create a tag such as `0.0.2` (or `v0.0.2`) and publish.
4. The GitHub Action attaches `module.json` and `module.zip` to the release. Foundry then picks up the new version from the manifest URL above.
